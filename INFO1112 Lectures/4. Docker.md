- ==VM=='s virtualise the ==OS applications== layer as well as the ==OS kernel==
	- VMs have their own Kernel
	- Slower than Docker
	- Compatible with all OS systems
- ==Docker== only virtualizes the ==OS applications== layer
	- Containerises apps sitting above OS kernel 
	- Much quicker to start/run
	- Only compatible with Linux

## Docker:
### Docker Desktop
- Created to enable Docker use on Windows and Mac
- Uses hypervisor layer with a light Linux os kernel under the Docker container
- Includes:
	- Docker engine
	- Client GUI
	- Client CLI 

### Docker Image
The Docker Image of an app contains all of these packaged together:
- Source code
- Environmental Variables
- Environment Configuration (Similar to how Java needs node and npm)
- Directory structure and files
- Images are versioned as software can occur
	- Each version is noted by tags
	- '-Latest' often refers to the latest version
Official Images are created by the authors of the software, or in collab with the docker community
- Verified by Docker

### Docker Container
The **running instance** of a Docker Image is called the **Docker Container**
- Starts and runs the application artifact (image)
- Creates the environment
- Can have multiple containers from one image (Multiple instances)

### Docker Commands
```bash
#lists local images
$ docker images
IMAGE ID      DISK USAGE   CONTENT   SIZE   EXTRA

#lists currently running containers (instances)
#  -a    tag shows all containers (Running and not running)
$ docker ps
CONTAINER ID   IMAGE   COMMAND   CREATED   STATUS   PORTS   NAMES

#Used to download image from Docker Hub
#Default tag is latest
$ docker pull <image_name>:<tag>
309384029343: Random data code

#Creates container from Image and starts it
#Creates new everytime, even if previously created
$ docker run <image>
#    Can pass other commands (default is /bin/sh)
# Tags:
	# -it                        Interactive mode
	# -d                         Run in background
	# sh                         To use shell (In certain distro containers e.g
	#                             alpine)
	# ... --name <name> <image>  To set a name for the container
	# 

#To reuse a previously created container
$ docker start <container_id>

#Stops running a container
$ docker stop <container_id>

#Shows log of a container
$ docker logs <container_id>


```
