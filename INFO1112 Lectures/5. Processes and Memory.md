## Processes / Unix Kernel
- Many programs stored in memory
- Each cpu can only run 1 at a time
- Kernel is responsible for switching between the programs
	- Happens through an ==interrupt==
- **Interrupt:**
	- Currently running program is "interrupted" and its "state" is stored in memory
	- *State:* memory content, cpu registers...
	- The kernel can restore the program from its previous state
