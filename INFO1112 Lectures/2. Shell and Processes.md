## The Shell
[[Shell Commands]]
- Shell commands can be used with certain applications to be extremely powerful

### Shell variable
```bash
#Assigning values to shell variables:
$ NAME=bob

#Retrieving variables:
$ echo $NAME
bob

#Shell variables only hold strings
#Variable could contain filename:
$ FILE=fred.txt
$cat $FILE
some text in file called fred.txt

#To performt integer arithmetic,  place operators and integers inside (( double brackets )), otherwise integers will be treated as regular strings. 
$ echo 5 + 3
5 = 3
$ ((5 + 3))
$ echo $?
0

#Important to note that there is no output in this case. The exit codes of the function are as follows:
# - non-zero mathemtical result = 0 (succss exit code)
# - zero result = 1

#To hold te result of the arithmetic, we can use Arithmetic Interpolation which is $(( Logical Arithmetic))
$ var=$((5 + 3))
$ echo $var
8

#While variables are technically strings, they can still be used as integers by using expr application program
#expr looks at its arguments and treats them as arithmetic
$ A=1
$ A='expr $A + 1'
$ echo $A
2
```


### Redirection / Pipe
```bash
#Redirect output of a command to a new file instead of stout (terminal window)
#If the file exists, it will overwrite its current contents
$ echo hello > myfile
#Use >> to append if the file already exists
$ echo hello >> myfile


#Use a pipe to take the output of one command and sent it as input to another
$ cat hello.txt | wc -l
6
```


### Shell scripts
```bash
#Shell commands can be turned into programs called shell scripts (.sh)
#First line is always used to interpret the type of script
#!/bin/bash <-
echo $1 is your name
	  ^- special variable specifying the first argument

#e.g
$ ./script.sh riley
riley is your namee
```

### Shell For-Loop
```bash
#List of values could either be each value listed like this separated by spaces, or * to mean all files in directory:
for variable in {list of values}
do
	echo variable is $variable
done
```
