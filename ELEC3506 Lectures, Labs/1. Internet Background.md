# Networks
- A network is simply a set of interconnected computers

### LANs
- Networks for devices withing a limited geographical location, like an office building, campus, or home network
- Equipment/Technology:
	- Ethernet
	- FDDI
	- Token Ring
	- WLAN
	- Bridges
	- Switches
	- Routers

### MANs
- Connects a **Metropolitan** area (City), by linking multiple LANs together
- Switched Multimegabit Data Service (SMDS)
	- Connectionless packet-switching service, meaning it doesn't require an end-to-end circuit to be set up before transmitting data
- Asynchronous Transfer Mode (ATM)
	- Works by splitting data into 53-byte cells, and sets up a predetermined virtual route before any data is sent
	- Extremely reliable as it would guarantee a specific bandwidth and route
- Fiber Distributed Data Interface (FDDI)
	- **Dual Ring topology**: Where all the devices in a network are connected to 2 others, forming a ring network. There are two of these in opposite directions, one as the main and the 2nd as a backup
	- Passes a token around; only the computer with the token is allowed to transmit data
