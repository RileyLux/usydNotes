# 1. The Internet & Network Classifications

- **Core Definition**:
	- A global system of interconnected networks and nodes using standardized transmission, switching, and protocol suites to move data.
	- **Protocol**: A formal set of rules and conventions governing the format, timing, and sequence of data exchange between communicating entities.

### Network Classification by Geographic Scale
- **LAN (Local Area Network)**:
	- Limited geographic scope (office, campus, home, data center).
	- Common technologies: Ethernet (IEEE 802.3), Wi-Fi (IEEE 802.11), Token Ring, FDDI.
	- Core hardware: Layer 2 switches, bridges, access routers.
- **MAN (Metropolitan Area Network)**:
	- Covers a city-wide area; serves as a regional backbone linking multiple LANs.
	- Key technologies:
		- **SMDS (Switched Multimegabit Data Service)**: Connectionless, packet-switched transport based on IEEE 802.6 DQDB standard.
		- **ATM (Asynchronous Transfer Mode)**: Splits data into fixed 53-byte cells; pre-establishes virtual circuits with guaranteed QoS.
		- **FDDI (Fiber Distributed Data Interface)**: Dual counter-rotating ring topology with token-passing for fault tolerance.
		- **Metro Ethernet & Wireless MESH**: Modern high-speed metropolitan distribution.
- **WAN (Wide Area Network)**:
	- Spans long distances (inter-city, national, global).
	- Technologies: MPLS (label switching replacing full IP routing lookups), Frame Relay, ATM, X.25.
- **Access Network**:
	- Connects customer premises (LANs/endpoints) to the ISP core network.
	- Examples: FTTH (Fiber to the Home), xDSL, 4G/5G cellular base stations, cable DOCSIS.

# 2. Historical Context & Formal Definition

- **FNC Formal Definition (1995)**:
	- The Federal Networking Council defined the Internet as a global system:
		1. Logically linked by a globally unique address space based on IP.
		2. Supporting communication via TCP/IP or compatible protocol suites.
		3. Providing and layering high-level services over underlying network infrastructure.
- **Key Milestones & Pioneers**:
	- **1972**: Kahn demonstrated ARPANet at ICCC; introduction of network email.
	- **1980s**: ARPANet split into military (**MILNet**) and civilian/research (**ARPANet**); international expansion.
	- **1991–1992**: Tim Berners-Lee created the World Wide Web (WWW) at CERN; public release catalyzed commercial internet explosion.
	- **Fathers of the Internet**: Robert Kahn and Vinton Cerf (co-inventors of TCP and IP).

# 3. Layered Architecture & Encapsulation

- **Why Layering?**:
	- Decomposes complex communication tasks into modular, self-contained layers.
	- Each layer provides defined services to the layer above and relies on services from the layer below.
	- Standardized interfaces enable independent protocol evolution without breaking adjacent layers.
- **Encapsulation & Decapsulation**:
	- **Transmitter (Encapsulation)**: Each layer appends a protocol-specific header (and Layer 2 trailer) to the payload received from above.
	- **Receiver (Decapsulation)**: Each layer inspects, strips its header, and passes the payload upward.
- **Three Scopes of Delivery**:
	- **Hop-to-Hop (Data Link)**: Delivers frames between adjacent physical nodes; physical MAC addresses change at each hop.
	- **End-to-End (Network)**: Delivers packets from source host to destination host across intermediate routers; IP addresses remain unchanged.
	- **Process-to-Process (Transport)**: Delivers messages between specific application processes using 16-bit port numbers.

# 4. OSI 7-Layer Reference Model vs. TCP/IP

### The 7 OSI Layers
1. **Physical Layer**:
	- Transmits raw bits over a physical medium.
	- Specifies voltage levels, line coding, bit synchronization, and transmission modes (simplex, half-duplex, full-duplex).
2. **Data Link Layer**:
	- Ensures reliable hop-to-hop frame delivery over a single physical link.
	- Handles framing, MAC addressing, flow control, error detection (CRC), and access control.
3. **Network Layer**:
	- Delivers packets end-to-end across multiple interconnected networks.
	- Manages logical addressing (IPv4/IPv6) and routing path selection.
4. **Transport Layer**:
	- Manages process-to-process message delivery.
	- Uses 16-bit port numbers; handles segmentation, reassembly, connection control, and end-to-end flow/error control (TCP vs. UDP).
5. **Session Layer**:
	- Manages communication dialogs (half/full-duplex) and synchronization checkpoints for session recovery.
6. **Presentation Layer**:
	- Handles data representation: syntax/semantics translation (ASCII, Unicode), data compression, and encryption/decryption (TLS).
7. **Application Layer**:
	- Exposes network services directly to end-user software (HTTP, DNS, FTP, SMTP).

### TCP/IP Protocol Suite (5-Layer Pragmatic Model)
- Condenses OSI Session, Presentation, and Application layers into a single **Application Layer**.
- Structure: **Physical $\to$ Data Link $\to$ Network (Internet) $\to$ Transport $\to$ Application**.
- **Addressing Hierarchy**:
	- **Physical (MAC)**: 48-bit local interface address (changes hop-to-hop).
	- **Logical (IP)**: 32-bit (IPv4) or 128-bit (IPv6) global host identifier (end-to-end).
	- **Port Address**: 16-bit application process identifier (e.g., HTTP = 80, DNS = 53).
	- **Specific Address**: Application-level identifiers (URLs, email addresses).

# 5. Key Standards Organizations

- **IETF (Internet Engineering Task Force)**: Develops open Internet standards published as **RFCs (Request for Comments)**.
- **ISO (International Organization for Standardization)**: Global standards body responsible for the OSI reference framework.
- **ITU-T (International Telecommunication Union - Telecom Sector)**: UN specialized agency defining telecommunications and modem standards.
- **ANSI (American National Standards Institute)**: Coordinates US voluntary standards and represents the US within ISO/ITU-T.
